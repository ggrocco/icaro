Run AI coding agents in parallel

Ícaro is an open-source tool for running Claude Code and Codex on your machine. Give each task its own Git worktree and Docker container, then automate repeatable development tasks with YAML workflows.

Install Ícaro

How coding agent sessions work

  1. Start an agent session. Ícaro creates a Git worktree on a separate branch so each task can edit its own checkout.
  2. Run the agent as a non-root user in an isolated Docker container with a profile-specific network allowlist and without access to the Docker socket.
  3. Open a live preview at a per-session .localhost URL when the project has a Docker Compose stack configured for previews.
  4. Record decisions and handoffs in shared project memory via the Model Context Protocol (MCP).

Automate development workflows

Connect coding agents, container commands, and integrations such as GitHub or Slack in a YAML workflow. Set step dependencies so independent work can run in parallel, and pause for approval when a person needs to review the result.

Start a workflow manually, on a cron schedule, or from an inbound webhook. Follow step outputs and logs in the local web UI, or try the hello workflow example without an agent-provider login.

Isolation and credential handling

Network allowlists

Each agent profile defines which hosts its containers can reach.

Managed profile homes

Log in once per profile. Ícaro keeps profile logins separate from your host credentials.

Host-bound credentials

The daemon stores integration tokens and sends them only to approved hosts.

Signed releases

The installer and icaro update verify the release signature and checksums.

Install Ícaro on macOS or Linux

Install Git and start Docker first. The release installer also requires OpenSSL 3.0 or newer for signature verification.

curl -fsSL https://github.com/ggrocco/icaro/releases/latest/download/install.sh | sh
icaro init
icaro setup

On macOS, you can also install with brew install ggrocco/tap/icaro. Follow the quickstart to launch a coding agent or find other builds on the GitHub releases page.

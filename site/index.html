GitHub Docs Security

Many agents, flying in parallel. None of them too close to the sun.

Ícaro runs coding agents side by side. Each gets its own git worktree, an isolated container with a locked-down network, a live preview URL, and shared memory with the others.

Install

One primitive: the session

  1. Create a worktree for the branch the agent will work on.
  2. Start the agent in an isolated container. It runs non-root with no Docker socket, and egress is limited to its provider.
  3. Open the app at a predictable preview URL. The preview updates as the agent edits.
  4. Record decisions and handoffs in shared memory over MCP, scoped to the project.
  5. Optionally orchestrate sessions with a workflow, triggered by webhooks or cron.

Why it is safe to leave running

Mandatory egress

Every agent container is confined to an allowlist of provider endpoints. A prompt-injected agent cannot reach anything else.

Managed homes

You log in once per profile. Your real ~/.claude is never mounted.

Host-bound credentials

Integration tokens never leave the daemon, and each one is sent only to the hosts you confirmed for it.

Signed releases

The installer and icaro update verify an ed25519 signature and the checksums before they replace anything.

Install

curl -fsSL https://github.com/ggrocco/icaro/releases/latest/download/install.sh | sh
icaro init && icaro doctor

Requires Docker on Linux or macOS. Homebrew: brew install ggrocco/tap/icaro. To start at login: icaro service install.

# Phase 10 — Documentation and landing page

**Objective:** public docs and mythological identity.

**Depends on:** see the [roadmap](../04-roadmap.md#dependencies), which also defines the entry, test, and exit rules every phase follows.

## Deliverables

- [x] Build a static, lightweight GitHub Pages landing page ([`site/`](../../../site/index.html), [`pages.yml`](../../../.github/workflows/pages.yml)).
- [x] Write quickstart, security, workflows, previews, and FAQ ([`docs/`](../../../docs/README.md): quickstart, sessions, workflows, integrations, previews, memory, agents, UI, security, FAQ, upgrading, and a [CLI reference](../../../docs/cli.md) generated by `hack/gendocs` and checked in CI).
- [x] Use the Ícaro artwork with a license and alt text ([`site/icaro.svg`](../../../site/icaro.svg), CC BY 4.0).
- [x] Create reproducible examples ([`examples/`](../../../examples/), plus the `yaml workflow` blocks in the docs; `hack/docscheck` validates all of them).
- [x] Add CONTRIBUTING, CODEOWNERS, SECURITY, and a roadmap ([CONTRIBUTING](../../../CONTRIBUTING.md), [CODEOWNERS](../../../.github/CODEOWNERS), [SECURITY](../../../SECURITY.md), [roadmap](../04-roadmap.md)).

## Acceptance criteria

- [x] The quickstart passes in the CI/documentation test (`go test -tags e2e ./hack/quickstart` runs the `sh quickstart` blocks of [docs/quickstart.md](../../../docs/quickstart.md) against a real daemon and Docker in the `e2e` job).
- [x] No broken links (`hack/linkcheck` runs in the [docs workflow](../../../.github/workflows/docs.yml) on every PR).
- [x] Examples use images pinned by digest (`hack/docscheck` fails on an unpinned `image:` in `examples/` or in a docs workflow block).
